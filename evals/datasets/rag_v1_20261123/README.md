# V1 企业知识问答（RAG）三层评测数据集（`v1_20261123/rag`）

本目录存放 **企业知识文档问答与受控问数（RAG + ChatBI）** 的 V1 基准数据集，严格划分 **检索层、安全对抗层、行为质量层**。

## 文件清单

| 文件名 | 规模 | 说明 |
|---|---|---|
| `cases.jsonl` | 180 例（27 个子类 / 9 大领域角色） | 覆盖商品规格、兼容性、售后、运营、供应链、财务、多跳计算、时效、长上下文及 ChatBI |
| `corpus_docs.jsonl` | 42 篇文档 | 与 `cases.jsonl` 配套的企业语料与多版本/多密级/跨部门权限夹具 |
| `manifest.json` | 元数据清单 | 记录生成参数、`seed` 与语料/用例统计摘要 |
| `golden_adversarial.json` | 18 例 | 全自动规则判定的安全对抗集（提示词注入、越权、撤权、金丝雀防泄漏、拒答边界） |

## 常用执行入口

```bash
make evals-quick
make evals-full
```
