# V1 基准评测数据集（`v1_20261123`）

本目录为淘智（TaoZhi-EcomAgent）**V1 基准版本评测数据集**，严格按评测体系与分层结构归档留存。已定版版本目录只读保存，后续任何数据集扩展或修订均须新建 `v2_<时间戳>` 目录，严禁原地覆盖本目录文件。

## 目录结构

| 子目录 | 适用评测体系 | 数据内容 | 说明文档 |
|---|---|---|---|
| `agent/` | 多智能体调研评测（`evals/agent_eval`） | 合成基准用例（12 例）、标准回放轨迹、定向反例集及网页边界样本 | [agent/README.md](agent/README.md) |
| `rag/` | 企业知识问答三层评测（`evals/rag_eval`） | 180 例主集（27 类 / 42 篇语料）与 18 例规则对抗集 | [rag/README.md](rag/README.md) |

## 版本演进规范

- **命名规则**：`v<主版本号>_<YYYYMMDD>`，例如 `v1_20261123`、`v2_20261201`。
- **不可变性**：已入库且跑过基线的版本只增不改，保证不同技术栈与 Prompt 版本的历史评测指标可跨期公平对比。
- **登记要求**：每次新增版本目录，须同步在本目录级 `README.md`、`STRUCTURE.md` 以及对应 `AGENTS.md` 中登记。
