# V2 基准评测数据集（`v2_20261124`）

本目录为淘智（TaoZhi-EcomAgent）**V2 基准版本评测数据集**，按评测体系分为 `rag/` 与 `agent/` 两个互不混用的子目录。已定版版本目录只读保存，后续扩展须新建 `v3_<时间戳>`，严禁原地覆盖本目录文件。

## 目录结构

| 子目录 | 适用评测体系 | 数据内容 | 说明文档 |
|---|---|---|---|
| `rag/` | 企业知识问答三层评测（`evals/rag_eval`） | 200 例主集、56 篇语料夹具与 30 例规则对抗集 | [rag/README.md](rag/README.md) |
| `agent/` | 多智能体调研评测（`evals/agent_eval`） | 200 例（10 例实测 + 190 例合成回放）、190 条观测与 190 条定向反例 | [agent/README.md](agent/README.md) |

## 相对 V1 的变化

- 分类口径统一为业界标准名称（RAG 27 类、Agent 20 类能力），不再使用缩写或自造词。
- RAG 主集 180 → 200 例，对抗集 18 → 30 例，语料 42 → 56 篇。
- Agent 22 → 200 例（10 例实测 + 190 例合成回放），每例配 1 条观测与 1 条定向反例，覆盖全部失败类型。

## 版本演进规范

- **命名规则**：`v<主版本号>_<YYYYMMDD>`，例如 `v1_20261123`、`v2_20261124`。
- **不可变性**：已入库且跑过基线的版本只增不改，保证历史评测指标可跨期公平对比。
- **可比性**：跨版本数据集不可直接比较，切换版本后须重新建立基线。
- **登记要求**：每次新增版本目录，须同步本目录级 `README.md`、`STRUCTURE.md` 以及对应 `AGENTS.md`。
