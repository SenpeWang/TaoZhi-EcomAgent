# 验证范围与复现

## 自动化门禁

- 仓库检查：禁止资料、本机维护约束、个人学习说明、私有配置、密钥、备份、构建和依赖；核验目录登记。
- 前端：锁文件安装、TypeScript 校验和 Vite 生产构建。
- 后端：Python 语法、独立 PostgreSQL 测试库的 Alembic 迁移和离线 pytest。
- 测试语料是代码中明确构造的最小合成事实，不依赖部署的 data/ 或真实模型凭据。
- 四身份浏览器：登录、可见菜单和资料、操作拒绝、退出切换身份及中文状态。

## 企业边界

| 范围 | 必验场景 |
| --- | --- |
| 企业与组织 | 第二企业、两个团队、伪造身份、猜测资源 ID、跨组读写 |
| 身份 | 员工只读、组长范围、管理员不能自提权、最后有效管理身份保护 |
| 文档 | 密级与组织、受限草稿、历史版本、上传、引用、下载及例外授权 |
| 授权变化 | 到期、撤销、调岗、离职、提高密级、删除和审核中撤权 |
| Agent | 机密标记不泄漏、资料指令不改变权限、外部模型许可、个人信息脱敏 |
| 任务 | 重复提交、租约过期、执行版本、崩溃恢复、取消、预算及有限重试 |
| 历史 | 无来源记录限制、来源版本变化、会话记忆及不同用户隔离 |
| 连接器 | 未接入、跨企业行、字段脱敏、过时数据、断连、超时和非法返回 |

## 执行

~~~bash
make check-repository
make test
make build-web
make verify-browser
~~~

测试库必须为 test 模式且数据库名为 ecom_v3_test。测试会清空专用库，禁止改成演示或正式库。测试和部署配置均不提交仓库；初始化方法见 [部署说明](ENTERPRISE_V3.md)。

slow 用例会调用模型，不属于离线 CI。真实模型验收仅使用演示资料，单独记录来源、费用预算、结果和限制。恢复演练仅在明确请求后生成私有备份，在独立数据库验证，不复用线上库。

## 证据记录

每次验收记录代码 commit、依赖锁、环境、命令、结果和已知限制；本机日志及截图归入 data/runtime/，不公开上传。公开说明只保留不含机密的概括，不能把历史检查当成本次结果。CI 结果以对应提交的 Actions 状态为准。

测试通过不代表真实业务连接器、多机高可用、SSO、附件恢复或异机备份已获部署验收；这些需要对应环境与业务负责人验证。
