# 数据目录说明

新增企业文档、数据集、导出和报告统一存放在本目录。项目代码位于 src/ 和 web/，软件维护说明位于 docs/。

| 目录 | 内容 |
| --- | --- |
| incoming/<tenant_id>/ | 新增真实企业文档与待解析附件，默认私有 |
| corpus/<category>/ | 带演示标记的示例商品资料，保留现有分类 |
| v3/<mode>/private/ | 已通过授权入库接口保存的私有原件 |
| runtime/ | 当前运行与验收日志、浏览器截图等生成物 |
| reports/<tenant_id>/ | 经授权导出的业务报告 |
| index/、embeddings/、graph/ | 现有离线索引和演示初始化所需数据 |
| state/ | 历史迁移原数据 |
| backups/ | 仅当用户明确要求时生成的手动备份 |

放入文件不等于发布。新增文档须明确企业、组织范围、密级和处理许可，经现有账号登录、解析和负责人审核后才可用于问答。真实机密不要混入可提交的演示语料，不要公开私有原件目录。

只在使用时创建具体子目录；临时文件完成后清理。后续维护遵循项目根目录 AGENTS.md。
