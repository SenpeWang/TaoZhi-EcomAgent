## 1. 文档说明

- 本表为 C1 高清钢化膜、C2 磨砂钢化膜、C3 防窥钢化膜、C4 水凝膜、C5 柔性陶瓷膜的**逐机型适配判定总表**。
- 图例：**✔ = 适配**；**— = 不适配**。
- 本表与「膜切云」刀模库按月同步更新；本表与商品页冲突时以本表为准，并反馈产品中心。

## 2. 适配判定规则

| 规则 | 内容 |
| --- | --- |
| 直板屏 | 钢化膜类（C1/C2/C3）与 C5 均可适配；等深微曲屏（如小米 15 系列、三星 S24/S25 系列）按直板处理 |
| 大曲率曲面屏 | 仅 C4 水凝膜可贴；钢化膜类（C1/C2/C3/C5）一律不适配 |
| 折叠屏内屏 | 仅 C5 柔性陶瓷膜（柔性全胶）；C4 及钢化膜类均不适配 |
| C3 专属限制 | 仅 iPhone 14~17 直板全系（含 Plus/Pro/Pro Max/16e/17 Air）；其他机型一律 — |
| C4 兜底逻辑 | 曲面屏与未开模机型可用 C4（膜切机或手工裁切）；直板机可贴但优先推荐 C1/C2 |
| 出厂年份维护 | 适配数据按机型发布时间维护，与膜切云刀模库同步；新机型发布后 14 个自然日内上线刀模并更新本表 |

## 8. 易错点 FAQ（客服必读）

| 问题 | 标准答复 |
| --- | --- |
| C3 能不能贴 Mate 70 Pro？ | **不能**。C3 仅适配 iPhone 14~17 直板全系；且 Mate 70 Pro 是曲面屏，钢化膜无法贴合。曲面屏请选 C4 水凝膜。 |
| Mate 60 Pro+ 有钢化膜吗？ | 没有。曲面屏机型不适配 C1/C2/C5，选 C4 水凝膜（膜切机或手工裁切）。 |
| 小米 14 Pro 能贴 C1 吗？ | 不能，曲面屏不适配钢化膜，选 C4。小米 15 全系（含 Pro/Ultra，等深微曲按直板处理）可贴 C1。 |
| Mate X6 内屏贴什么膜？ | C5 柔性陶瓷膜，折叠屏专用，柔性全胶不碎边。 |
| iPhone 13 能贴 C3 防窥膜吗？ | 不能，C3 仅适配 iPhone 14~17；13 系列请选 C1 高清或 C2 磨砂。 |
| 新发布的手机没有膜怎么办？ | 用 C4 水凝膜按机型裁切（MC-300/MC-500 或手工）兜底；刀模每月更新，新机发布后 14 个自然日内上线。 |
| C4 能贴直板机吗？ | 能，但直板机首选 C1/C2 钢化膜（防刮与抗冲击更优）；C4 的核心价值在曲面屏与未开模机型。 |
| 三星 S25 Ultra 有钢化膜吗？ | C1/C2 暂未开模，可选 C5 陶瓷膜（直板旗舰适配）或 C4 裁切。 |
| 贴了 C4 后有细小气泡正常吗？ | 正常，24~48 小时内自动消散；细微划痕也会自动修复。 |
| 为什么 C3 那么贵还只有 iPhone 14~17？ | 28° 防窥光学层成本高；防窥层为平面光学结构，曲面屏/折叠屏物理上不可贴。 |
