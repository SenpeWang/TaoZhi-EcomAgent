## 1. 文档说明

- 本表为 MC-300（入门）与 MC-500（旗舰）两款膜切机的**膜材支持矩阵、刀模库口径与耗材更换指引**。
- 膜切机用于将整片膜材按机型刀模裁切成型；机型×膜款的适配判定见《机型适配总表_钢化膜与水凝膜》（MF-SX-2026-001）。
- 设备电气参数与装箱清单见《膜切机规格书_MC300_MC500》（MF-SP-2026-006）。

## 2. 设备×膜材支持矩阵

| 膜材 | 品名 | MC-300 | MC-500 | 备注 |
| --- | --- | --- | --- | --- |
| C1 | 高清钢化膜 | ✔ | ✔ | 成品膜机型为主，裁切用于特殊尺寸场景 |
| C2 | 磨砂钢化膜 | ✔ | ✔ | 同上 |
| C3 | 防窥钢化膜 | — | ✔ | 防窥膜需 MC-500 专用刀模（0.38mm 厚材） |
| C4 | 水凝膜 | ✔ | ✔ | TPU 柔材，两机主力裁切对象 |
| C5 | 柔性陶瓷膜 | — | ✔ | 陶瓷膜需 MC-500（0.15mm 柔材专用刀模） |
| B1 | 磨砂背膜 | ✔ | ✔ | PET 柔材，批量连切常用 |

> 口径：MC-300 支持高清膜/水凝膜/背膜（C1/C2/C4/B1）；MC-500 双刀头支持全系膜材（含防窥膜/陶瓷膜 C3/C5）。

## 4. 耗材更换指引

### 4.1 N1 膜切机刀头（标准 45°）

| 项目 | 口径 |
| --- | --- |
| 规格 | 标准 45° 刀头 |
| 寿命 | 约 **3000 次裁切**（正常膜材） |
| 适用设备 | MC-300 / MC-500 |
| 更换判定 | 裁切不透、边缘毛刺增多、切痕偏移时更换；或按计数临近 3000 次预防性更换 |

**更换步骤：**

1. 关机断电，打开刀头仓。
2. 旋下旧刀头，清理仓内废屑（用随箱清洁刷）。
3. 装入新 N1 刀头并旋紧，避免磕碰刀尖。
4. 开机后在「膜切云」APP 中执行**刀头校准**流程。
5. 试切一张 C4，检查切口是否光滑无毛刺，确认后恢复量产。

> 禁止使用非原厂刀头；使用非原厂耗材导致的精度异常不在保修范围。

### 4.2 M3 切垫（A4）

| 项目 | 口径 |
| --- | --- |
| 规格 | A4 幅面切垫 |
| 适用设备 | MC-300 / MC-500 |
| 更换判定 | 垫面划痕密集、压痕不回弹、膜片打滑或切不透时更换 |
| 使用注意 | 裁切位置尽量均匀分布，避免长期集中于同一区域 |

### 4.3 日常保养

| 频次 | 项目 |
| --- | --- |
| 每日 | 清理仓内废屑，检查切垫表面 |
| 每周 | 检查刀头状态，擦拭导轨（禁止使用酒精以外溶剂） |
| 每月 | 随膜切云更新核对刀模版本；检查紧固件 |

## 5. 常见问题 FAQ

| 问题 | 标准答复 |
| --- | --- |
| MC-300 能切防窥膜 C3 吗？ | 不能。C3 防窥膜与 C5 陶瓷膜需 MC-500（双刀头、120mm 切幅、专用刀模）。 |
| MC-300 能切陶瓷膜 C5 吗？ | 不能。同上，需 MC-500。 |
| 两款机器用什么 APP？ | 均为「膜切云」。MC-300 通过蓝牙 4.2 连接；MC-500 支持蓝牙 5.0 + Wi-Fi。 |
| 刀模多久更新一次？ | 每月更新，推送当月新增机型清单；新机型发布后 14 个自然日内上线。 |
| 刀头能用多久？ | N1 标准 45° 刀头寿命约 3000 次裁切，出现毛刺/切不透应立即更换并校准。 |
| 新手机刀模还没有怎么办？ | 用 C4/B1 整片手工裁切过渡，刀模上线后改用标准裁切。 |
| 裁切偏位怎么办？ | 先执行 APP 内刀头校准；仍偏位则检查切垫是否到期、刀头是否磨损，必要时更换 M3/N1。 |
| MC-300 刀模能更新到 MC-500 的规模吗？ | 不能。两机刀模库规模（12000+/20000+）与切幅（90mm/120mm）为硬件口径，不可相互升级；需 C3/C5 裁切请配置 MC-500。 |
| 更新需要付费吗？ | 膜切云刀模月度更新为设备配套服务，经销商账号分级权限详见 MF-SP-2026-006。 |
