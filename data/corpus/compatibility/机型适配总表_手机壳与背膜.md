## 1. 文档说明

- 本表为 S10 液态硅胶壳、T20 MagSafe 透明壳、A30 气囊防摔壳、B1 磨砂背膜的**逐机型适配判定总表**，附录含 L1 镜头膜适配清单。
- 图例：**✔ = 适配**；**— = 不适配**。
- 手机壳不受屏幕曲率限制（壳体包覆边框），适配取决于开模机型；B1 为裁切型背膜，直板与等深微曲机型均可按机型裁切使用。

## 2. 判定规则

| 规则 | 内容 |
| --- | --- |
| T20 机型范围 | 仅 iPhone 12~17 全系。iPhone 12 起机身才内置 MagSafe 磁吸阵列，iPhone 11 及更早机型与全部安卓机型无 MagSafe，T20 一律不适配 |
| S10/A30 开模 | 按已开模机型适配；安卓侧以「主流安卓直板机」为开模范围，曲面屏机型暂未开模 A30 |
| B1 裁切逻辑 | B1 为整片出厂、按机型裁切，直板与等深微曲机型均可；折叠屏不适配；不影响无线充电（PET 非金属材质） |
| 屏幕形态 | 大曲率曲面屏机型（如 Mate 60 Pro/Pro+/RS、Mate 70 Pro/Pro+/RS、小米 14 Pro/14 Ultra、Magic6 Pro/Magic7 Pro）仅壳体类可覆盖，A30 暂未开模 |
| 数据同步 | 与「膜切云」开模清单按月同步，新机型发布后 14 个自然日内更新本表 |

## 8. 磁吸兼容说明（客服必读）

| 问题 | 标准答复 |
| --- | --- |
| 哪些机型自带 MagSafe？ | **iPhone 12 起**（12/12 mini/12 Pro/12 Pro Max 及之后全系）机身内置 MagSafe 磁吸阵列；iPhone 11 及更早机型、全部安卓机型均无 MagSafe |
| T20 能给安卓机用吗？ | 不能。T20 仅适配 iPhone 12~17 全系；安卓机无 MagSafe 模块，磁吸无着力点 |
| 安卓机想要磁吸怎么办？ | 使用 G1 指环支架（N52 磁吸）+ 金属贴片方案；详见《贴膜配件规格书_P1_K1_G1》（MF-SP-2026-005） |
| T20 磁吸会不会掉？ | 不会。N52 磁吸环与标准 MagSafe 附件对拉拉脱力 ≥8N，日常使用、车载场景吸力充足 |
| T20 影响无线充电吗？ | 不影响。磁吸环隔离注塑，兼容 MagSafe 无线充、磁吸充电宝、磁吸车载支架 |
| B1 背膜影响 MagSafe/无线充电吗？ | 不影响。B1 为 PET 材质，非金属，不屏蔽磁场 |
| S10 有磁吸吗？ | 没有。液态硅胶壳不带磁吸；需要磁吸选 T20，或搭配 G1 |
