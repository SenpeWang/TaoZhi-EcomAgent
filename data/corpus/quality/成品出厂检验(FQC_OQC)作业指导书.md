---

## 1. 目的

规范成品出厂最终检验（FQC）与出货检验（OQC）作业动作、判定与记录要求，确保出货批次质量一致、可正向追溯与反向召回。

## 2. 职责

| 岗位 | 职责 |
| --- | --- |
| FQC 检验员 | 按 GB/T 2828.1 抽样，全项目复测并拍照 |
| OQC 签核人 | 质量工程师及以上，判定放行，签合格证书 |
| 产线组长 | 不合格批隔离、停线纠正、8D 发起 |
| 仓储发货 | 凭合格证与批次号出库，条码绑定 |

## 3. 检验流程

```
成品入库待检
  ↓ 按批量字码抽样本
FQC 全项目复测（光学/力学/尺寸/胶层/包装）
  ↓ 判定
合格 → OQC 签核 → 贴合格证（批次号+工号）→ 出库
不合格 → 红区隔离 → 返工/让步/报废（按 MF-QC-2026-001 第 6 章）
```

## 4. 关键控制点

1. 抽样方案：一般检验水平 II，AQL 1.0（主缺陷）/2.5（次缺陷），加严 AQL 0.65。
2. 每批留存封样至售后期满，检验记录保存 3 年。
3. 致命缺陷（Cr）Ac=0，发现 1 件整批拒收。
4. 市场端同批投诉 ≥5 起触发召回（见 MF-QC-2026-001 第 6.5 条）。

## 5. 记录与追溯

批次号规则 `Q + 年月日 + 班次 + 流水`（例 Q20260401A012），与 SKU 条码绑定，录入 QMS 可双向追溯。
