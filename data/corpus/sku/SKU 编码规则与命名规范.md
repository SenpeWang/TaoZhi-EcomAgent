# SKU 编码规则与命名规范

## 1. 编码结构

`MF-<品类><规格>-<颜色/版本>-<流水>`，例 `MF-C1-CLR-001`（C1 高清透明）。

## 2. 品类码

| 码 | 品类 |
| --- | --- |
| C | 膜类 |
| S | 壳类 |
| P | 配件 |
| M | 设备 |
| U | UV 耗材 |

## 3. 命名

中文名 + 型号 + 属性，与条码一致；禁止同物多码。

## 4. 维护

新增 SKU 由商品管理中心在 ERP 建档，条码与质检批次绑定。
