## 1. 说明

本日志汇总膜法工坊全系设备的固件版本发布记录。固件通过「膜切云」APP（膜切机 MC-300/MC-500）与设备本机菜单（UV 打印机 UV-600/UV-900）推送更新。

**升级通用注意事项：**

1. 升级前确认设备供电稳定，禁止在升级过程中断电、退出 APP 或关闭蓝牙。
2. 升级过程约 3~5 分钟，期间设备不可进行裁切/打印作业。
3. 升级失败可重启设备后重试；连续 2 次失败请联系售后热线 400-680-9527。
4. 固件升级不影响整机 1 年质保；禁止使用非官方渠道固件（视为人为损坏）。

## 2. MC-500 膜切机固件记录

### 2.1 版本总表

| 固件版本 | 发布日期 | 更新要点 |
| --- | --- | --- |
| V2.3.1（当前） | 2026-08-20 | 新增 Mate X6、iPhone Air 刀模；批量连切稳定性修复 |
| V2.2.0 | 2026-05-14 | 支持陶瓷膜 C5 裁切参数 |

### 2.2 V2.3.1（2026-08-20）

| 更新点 | 说明 |
| --- | --- |
| 新增刀模 | Mate X6（C5 陶瓷膜折叠屏刀模）、iPhone Air 刀模 |
| 批量连切修复 | 修复连切第 6 张后偶发基准偏移问题，连切稳定性提升 |
| 其他 | E5 刀头过载判定阈值优化，减少误报停机 |

**升级方法：** 打开膜切云 APP →「设备 → 固件更新」→ 检测到 V2.3.1 → 保持蓝牙连接与 2.4GHz 网络稳定 → 点击「立即升级」→ 语音提示「升级完成」。

**注意事项：**

1. 升级完成后需重新执行一次「校准向导」，确保基准精度。
2. 使用批量连切的门店请在升级后试切 3 张验证再上量产。
3. Mate X6 刀模需配合 C5 陶瓷膜参数使用，禁止用 C1 参数替代。

### 2.3 V2.2.0（2026-05-14）

| 更新点 | 说明 |
| --- | --- |
| 新增膜材 | 支持陶瓷膜 C5 裁切参数（0.15mm 全胶，折叠屏刀模库同步上线） |
| 刀压优化 | C5 专用刀压曲线，避免全胶层拉丝 |
| 前置条件 | 需膜切云 APP 升级至 V3.6 及以上 |

**升级方法：** 同 V2.3.1，APP 内在线升级。

**注意事项：** 升级前请确认双刀头安装到位；首次切 C5 前建议用废膜试切验证切缝质量。

## 4. UV-600 打印机固件记录

### 4.1 V1.8（2026-07-15）

| 更新点 | 说明 |
| --- | --- |
| 白墨循环改进 | 循环泵策略优化：循环时长自适应白墨黏度，沉淀打散更均匀 |
| 断线优化 | 修复白墨测试条偶发规律性断线（对应堵头一级场景） |
| 其他 | 1440dpi 模式下白墨出墨量微调，白度更均匀 |

**升级方法：** 设备本机「设置 → 系统更新」→ 检测到 V1.8 → 点击「下载并安装」→ 自动重启完成。

**注意事项：**

1. 升级完成后立即执行一次白墨循环（W-1L）并打印测试条留档。
2. 升级后首周请每日记录测试条，观察断线率变化；异常联系 400-680-9527。
3. 白墨每日循环的操作规范不变，固件优化不能替代日常保养（见 MF-SOP-2026-003）。

## 5. UV-900 打印机固件记录

### 5.1 V1.5（2026-04-10）

| 更新点 | 说明 |
| --- | --- |
| 新增功能 | 滚轴圆面打印支持（水杯、圆瓶类曲面介质） |
| 参数预设 | 内置圆面直径档位（60/70/80mm 常用规格） |
| 联动 | 与 UV-900 滚轴配件固件 V1.5 起配套使用 |

**升级方法：** 设备本机「设置 → 系统更新」→ 在线升级至 V1.5。

**注意事项：**

1. 圆面打印前必须校准滚轴同心度与介质直径档位，防止撞喷头。
2. 使用滚轴圆面打印需同步确认 XP600 ×3 喷头通道测试正常（先打测试条）。
3. 升级后请重新执行喷头对齐。

## 6. 升级前备份与回滚说明

1. 升级前记录：设备 SN、当前固件版本、校准偏差值（APP 截图存档），便于异常追溯。
2. 膜切机自定义刀压与常用机型收藏随固件升级保留，无需重设；校准数据升级后需重跑一次校准向导。
3. UV 打印机自定义 ICC 曲线保存在上位机软件中，固件升级不影响曲线文件，但需重新执行喷头对齐。
4. 官方不提供固件降级通道；新版本如存在兼容性问题，报设备研发部评估处理，禁止私下刷写旧版固件。
5. 升级后 48 小时内为观察期：膜切机试切留样，UV 打印机每日测试条留档。
6. 观察期出现异常先联系 400-680-9527 由值班工程师远程诊断，禁止自行拆机（自行拆解影响整机 1 年质保）。
