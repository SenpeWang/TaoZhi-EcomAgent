## 1. 安全与用电

1. 设备使用 220V 带地线插座，必须独立回路，禁止与大功率电器（烤箱、空压机）共用插排。
2. UV 灯与墨水区域禁止明火；UV 墨水避光、远离热源存放，存放温度 15~30℃。
3. 皮肤接触墨水后立即用肥皂水清洗；不慎入眼立即大量清水冲洗并就医。
4. 打印过程中禁止打开护罩，UV 光源直射眼睛与皮肤有害。
5. 维护保养、更换喷头前必须关机断电；带电插拔喷头将烧毁板卡且不在保修范围。
6. 异常停机、跳闸、焦味出现时，先断电再排查，并联系 400-680-9527。

## 2. 安装环境要求

| 项目 | 要求 | 超标影响 |
| --- | --- | --- |
| 温度 | 18~28℃（建议 22~26℃） | 低温墨水黏度上升，易断线堵头 |
| 湿度 | 40%~65% RH | 过低静电大、过高画面不干 |
| 水平度 | 台面水平误差 ≤1mm/m | 长期偏斜导致导轨偏磨、打图起边 |
| 供电 | 220V±5%，配地线 | 电压波动易烧喷头板卡 |
| 洁净 | 独立房间，避免风直吹喷头 | 粉尘导致堵头、打印有颗粒 |
| 摆放 | 四周预留 50cm 检修空间 | 影响维护与散热 |

安装步骤：开箱核对 → 拆除运输固定件 → 调平地脚（水平仪置于平台中心校验）→ 接电源（先接地线）→ 装墨（详见第 9 节）→ 试运行。

## 3. 开关机流程

### 3.1 开机

1. 确认墨水余量与废墨盒状态。
2. 打开设备总电源开关，等待系统自检（约 60 秒）。
3. 按下「启动」键，设备自动执行喷头清洁与白墨循环预热。
4. 打印测试条确认喷头状态正常后开始作业。

### 3.2 关机

1. 完成当日订单后，先执行一次「打印头复位」。
2. 点击软件「关机保养」按钮，系统自动完成白墨循环收尾。
3. 关闭软件 → 关闭设备电源 → 关闭总闸。
4. 超过 3 天不使用时，需在关机前执行墨栈保湿流程（见第 10 节保养周期表）。

> 严禁直接拔电关机：跳过白墨循环收尾会造成喷头内白墨干涸结晶，是堵头的第一大原因。

## 4. 白墨每日循环操作

UV 白墨 W-1L 中颜料密度大、易沉淀，**必须每日开机执行白墨循环**，长期停机则每日开机循环一次。

1. 开机进入「维护 → 白墨循环」界面。
2. 点击「启动循环」，系统驱动循环泵运转 5~10 分钟，白墨在管路中反复流动打散沉淀。
3. 循环中观察白墨盒内搅拌状态，循环泵声音异常（空转尖啸）立即停止并排查墨量——墨量低于 15% 时先加墨再循环。
4. 循环完成后打印白墨测试条，白块应均匀无断线。
5. 测试条异常时按第 8 节堵头处理流程操作。
6. 每次循环在《设备保养记录表》登记日期与测试结果，便于保修与故障追溯。

## 5. 打印前检查

| 序号 | 检查项 | 合格标准 |
| --- | --- | --- |
| 1 | 测试条 | 全部喷孔出墨，无断线、斜喷 |
| 2 | 墨量 | 各色墨 ≥15%，白墨 ≥20% |
| 3 | 温湿度 | 18~28℃ / 40%~65%RH |
| 4 | 平台 | 表面无残墨、无异物 |
| 5 | 夹具 | 牢固、位置与版对齐 |
| 6 | 耗材曲线 | 已选择与产品匹配的 ICC 曲线 |
| 7 | 废墨盒 | 未满（<80%） |

## 6. 手机壳打印流程

### 6.1 上夹具

1. 根据壳型选择对应定位夹具，夹具基准边对齐平台刻线。
2. 手机壳放入夹具压紧，印刷面朝上，确认无倾斜、无翘曲。
3. 多件排版时件间距保持 ≥5mm，防止撞喷头与串墨。

### 6.2 调高度

1. 用随机高度卡尺测量壳面最高点，喷头与印刷面间距设定为 2~3mm。
2. 带气囊结构的手机壳（如 A30 气囊防摔壳）以气囊最高点为基准。
3. 调整后手动滑车一个行程，确认无剐蹭再开始打印。

### 6.3 曲线选择

1. 在打印软件「介质曲线」中选择对应壳材曲线：液态硅胶壳选「Silicone-Std」，透明 MagSafe 壳（T20）选「Clear-Mag」，硬壳选「PC-Std」。
2. 白墨打印模式（先白后彩）用于深色壳；透明壳彩印选「仅彩色」。
3. 曲线选错是色彩偏差与附着力不良的主要原因，换介质必须换曲线。

### 6.4 打印与下件

1. 起始打印前 UV 灯预热 1 分钟。
2. 打印完成待 UV 固化灯走完最后行程后再下件，提前取件会发粘。
3. 下件后室温放置 2 分钟再包装，防止串色粘连。

## 7. 色差曲线校准

「打印颜色与设计稿偏差大」按以下流程校准：

1. 确认打印介质与所选曲线匹配（先查曲线，再谈校准）。
2. 打印标准色卡（软件内置 CMYKW 51 级色卡）。
3. 用分光仪或比对标准样张，记录偏色方向（整体偏黄/偏洋红等）。
4. 软件内进入「曲线编辑器」，微调对应通道墨量（建议单次调整幅度 ≤5%）。
5. 保存为新曲线版本并命名（如 `Silicone-Std-202608`），禁止直接覆盖原始曲线。
6. 重新打印色卡验证，色差 ΔE ≤3 视为合格。
7. 校准后仍严重偏色（大面积反色/串色），多为喷头通道异常，转第 8 节处理。

## 8. 堵头处理

堵头表现：测试条断线、画面出现规律性白道、颜色缺失。按由轻到重三级处理：

### 8.1 自动清洗（首选）

1. 「维护 → 清洗」选择标准清洗，耗时约 3 分钟。
2. 完成后打印测试条验证；无效可再执行 1 次。

### 8.2 手动清洗

1. 自动清洗 2 次仍断线时执行「维护 → 强力清洗」。
2. 强力清洗耗墨量大，单日不超过 2 次。

### 8.3 压墨

1. 上述无效时执行压墨（用注射器对喷头轻柔加压排堵）。
2. 仅限培训合格人员操作：压墨压力过大将冲坏喷头，喷头损坏不在免费保修范围。
3. 压墨后执行喷头对齐与测试条验证。
4. 三级处理仍无效 → 喷头可能永久性堵塞，联系 400-680-9527 报修（喷头质保期 3 个月）。

预防要点：**白墨每日循环（W-1L）、每日打印测试条、超过 3 天停机前执行保湿**。

## 9. 耗材更换

### 9.1 墨水更换

| 耗材 | 说明 | 更换要点 |
| --- | --- | --- |
| UV 白墨 W-1L | 需每日循环 | 余量低于 20% 加墨；加墨前摇匀；禁止混用他牌 |
| 彩墨套装 K-CMYK | C/M/Y/K 四色 | 按颜色独立加注，标签核对后倒墨 |

1. 加墨口颜色一一对应，禁止交叉加注（交叉即整路报废）。
2. 加墨后执行一次墨水初始化与测试条验证。
3. 墨水为耗材不保修；开封后保质期 6 个月，避光阴凉存放。

### 9.2 喷头更换

1. 寿命参考：XP600 正常使用寿命约 8~12 个月（视保养水平）。
2. 更换须由售后认证人员执行，涉及板卡接线与对位校准。
3. 喷头质保期 3 个月（自装机/更换日起算），人为烧毁（带电插拔、电压异常）不在保修范围。
4. 更换后必须重新执行喷头对齐与曲线校准。

## 10. 常见故障表

| 故障现象 | 可能原因 | 处置方法 |
| --- | --- | --- |
| 测试条规律断线 | 白墨沉淀未循环 / 喷头微堵 | 执行白墨循环 + 自动清洗 |
| 画面横向白道 | 单色断墨 | 打印测试条定位颜色后清洗对应通道 |
| 颜色整体偏差 | 曲线选错 / 曲线漂移 | 核对介质曲线后按第 7 节校准 |
| 画面重影错位 | 光栅污染 / 喷头对齐丢失 | 清洁光栅条；执行喷头对齐 |
| 附着力差易刮掉 | 未选 UV 涂层壳 / UV 固化不足 | 更换带涂层壳；核对固化灯功率与车速 |
| 白墨发稠出墨不畅 | 白墨超期 / 温度过低 | 更换 W-1L；环境升温至 18℃ 以上 |
| 设备报电压异常 | 插排过载 / 地线不良 | 独立回路供电，检查地线 |
| 打印中骤停 | 过热保护 | 关机 15 分钟散热，清理风道后重启 |
