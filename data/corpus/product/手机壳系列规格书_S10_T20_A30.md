## 1. 文档说明

- 本规格书覆盖膜法工坊（MofaLab）在售三款手机壳：**S10 液态硅胶壳、T20 MagSafe 透明壳、A30 气囊防摔壳**。

## 6. 磁吸标准说明（T20 相关，客服必读）

| 问题 | 口径 |
| --- | --- |
| 哪些机型机身自带 MagSafe | iPhone 12 起全系内置 MagSafe 磁吸阵列；iPhone 11 及更早机型、安卓机型均无 MagSafe 模块 |
| T20 适配范围 | 仅 iPhone 12~17 全系；无 MagSafe 模块的机型（含全部安卓）不适配 T20 |
| 磁吸性能口径 | N52 磁铁，与标准 MagSafe 附件对拉拉脱力 ≥8N |
| 兼容生态 | MagSafe 无线充电器、磁吸充电宝、磁吸车载支架均可正常吸附与充电（磁吸环经隔离注塑，不干扰无线充电） |
| 安卓/老机型的磁吸方案 | 使用 G1 指环支架（N52 磁吸，可 360° 旋转）实现磁吸支架/车载场景；详见 MF-SP-2026-005 |

## 7. 防摔测试依据说明（A30 相关，客服必读）

| 项目 | 口径 |
| --- | --- |
| 测试高度 | 1.5m（手持常见跌落高度上限） |
| 测试次数 | 26 次（六面、八角、多姿态组合点位，每次跌落为独立新机位） |
| 参照依据 | 参照 GB/T 2423.8 跌落试验方法与 MIL-STD-810H 方法 516.8 冲击试验，按企业内控规程 Q/MFL-QC-042 执行 |
| 测试地面 | 硬质地面（大理石） |
| 判定标准 | 测试后手机功能正常、屏幕与后盖玻璃无碎裂、壳体无断裂 |
| 客服表述 | 允许表述为「1.5m 防摔，通过 26 次跌落测试」；禁止表述为「防摔不坏/终身防摔」等绝对化承诺 |
