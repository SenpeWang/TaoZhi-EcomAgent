## 7. 贴附注意事项（客服与门店必读）

### 7.1 贴附流程

1. **停机清洁**：关闭手机，用酒精湿巾擦拭镜头组及 Deco 区域，纤维布擦干，除尘贴粘走浮尘。
2. **假对位**：先不撕离型膜，将 L1 置于镜头环上确认开孔与 Deco 完全同轴，再用定位贴临时固定一侧。
3. **正式贴附**：撕离型膜，沿定位贴铰链翻下镜片，从中心向外按压 10 秒，使回胶圈完全贴合。
4. **逐片检查**：每贴一片检查是否与 Deco 同轴、有无漏光缝隙，全部完成后静置。

### 7.2 禁止事项与风险提示

- **贴附后 12 小时内避免沾水与剧烈碰撞**，回胶层需要时间达到最终粘接强度。
- 严禁贴附后立即套用过紧手机壳；应先贴镜头膜再装壳，壳体镜头开孔需与 L1 外圈不干涉（本店在售 S10/T20/A30 手机壳镜头开孔已预留空间，以实物为准）。
- 镜片一旦碎裂立即停用，玻璃碎屑可能划伤原机镜头；售后按《售后FAQ与保修政策》处理。
- 拆除时从边圈缺口处缓慢掀起，禁止使用金属撬片；残胶用纤维布蘸少量酒精清除。

### 7.3 常见售后问题

| 问题 | 判定与处理 |
| --- | --- |
| 贴后偏位 | 24 小时内可返工一次，回胶层允许重新对位 |
| 拍照眩光/鬼影 | AF 层脏污所致时清洁即可；清洁后仍明显，按售后流程检测 |
| 金属圈氧化褪色 | 阳极氧化层正常磨损不在保修范围，人为磕碰掉漆不属于质量问题 |

### 7.4 常见问题 FAQ

| 问题 | 标准答复 |
| --- | --- |
| 镜头膜影响拍照画质吗？ | 正常无影响。镜片透光率 ≥92% 且带 AF 疏油层；如出现眩光/鬼影，先清洁镜片表面再判定。 |
| 铝合金圈会刮手或刮包吗？ | 不会。外圈经阳极氧化与倒角处理，边缘顺滑。 |
| 能和手机壳一起用吗？ | 能。先贴镜头膜再装壳；本店在售 S10/T20/A30 镜头开孔已预留 L1 空间（以实物为准）。 |
| 一套几片、能单买一片吗？ | 按机型整套装售卖，片数见 4.2；单片补购以门店在售 SKU 为准。 |
| 贴歪了怎么办？ | 24 小时内可揭起返工一次，回胶层允许重新对位，无残胶。 |
| 镜片碎了原机镜头会坏吗？ | 镜片为第一道牺牲层，碎裂后请立即停用并更换，避免碎屑划伤原机镜头。 |

## 8. 应用场景与卖点

- 核心话术：铝合金圈抗撞、9H 镜片防刮、AF 疏油不脏成像。
- 建议搭配：与 C1/C2 屏幕膜、A30 气囊防摔壳组成「全身防护」组合。
- 陈列建议：与对应机型手机壳同位陈列，镜头膜 + 手机壳连带率最高。
