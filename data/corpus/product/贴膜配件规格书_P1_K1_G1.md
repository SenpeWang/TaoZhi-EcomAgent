## 1. 文档说明

- 本规格书覆盖膜法工坊（MofaLab）三款贴膜与使用配件：**P1 贴膜神器、K1 清洁套装、G1 指环支架**。
- P1 与 K1 是贴膜交付的标准配件；G1 是磁吸支架类配件，与 T20 磁吸壳、MagSafe 生态配套。
- 关联产品规格见 MF-SP-2026-001 / 002 / 004。

## 3. P1 贴膜神器规格书

### 3.1 基本参数

| 参数项 | 规格 |
| --- | --- |
| 型号 / 品名 | P1 贴膜神器 |
| 功能 | 贴膜定位辅助，防止贴膜偏位与气泡 |
| 材质 | ABS 工程塑料 |
| 结构 | 框体式定位器，与膜片边框卡合对位 |
| 适配膜材 | C1 高清钢化膜、C2 磨砂钢化膜、C3 防窥钢化膜 |
| 不适用 | C4 水凝膜（裁切型）、C5 陶瓷膜（全胶直贴）、L1 镜头膜（独立定位贴）、B1 背膜（裁切型） |
| 单个净重 | 约 8g（以实物为准） |
| 包装 | 独立 PE 袋装 |

### 3.2 使用方法

1. 清洁屏幕后，将对应机型的 P1 框体卡入手机边框（P1 按机型分 SKU）。
2. 将钢化膜对准框体放入，膜片边缘与框体内壁贴合即完成对位。
3. 从中心向外抚压排气，待静电吸附完成后取下 P1 框体。

### 3.3 渠道与售卖口径

| 售卖形式 | 说明 |
| --- | --- |
| 零售单品 | 按机型独立售卖，购买前需核对机型 |
| 随膜赠品 | C1/C2/C3 **三片装** 附赠对应机型 P1 一只 |
| 门店服务 | 门店贴膜服务免费使用，不需单独收费 |

- 重要提醒：P1 按机型开模，跨机型不可通用；C5 全胶膜建议对位直贴，不使用 P1。

## 4. K1 清洁套装规格书

### 4.1 基本参数

| 参数项 | 规格 |
| --- | --- |
| 型号 / 品名 | K1 清洁套装 |
| 组成 | 除尘贴、酒精湿巾、超细纤维布 |
| 配置数量 | 除尘贴×6、酒精湿巾×3、超细纤维布×1、收纳袋×1 |
| 用途 | 贴膜前屏幕/镜头除尘清洁；日常屏幕清洁 |
| 适配范围 | 全系膜材（C1~C5、L1、B1）及屏幕日常清洁 |
| 收纳袋材质 | PE 密实袋 |
| 单套净重 | 约 30g（以实物为准） |

### 4.2 使用方法与顺序

1. 酒精湿巾整面擦拭，去除油污与指纹。
2. 超细纤维布擦干至无明显水痕。
3. 除尘贴滚粘屏幕表面，粘走浮尘（贴膜前最后一步）。
4. 超细纤维布可重复水洗使用，酒精湿巾与除尘贴为一次性耗材。

### 4.3 储存与保质期

| 项目 | 要求 |
| --- | --- |
| 酒精湿巾 | 密封保存，未拆封保质期 2 年，拆封后一次用完 |
| 除尘贴 | 粘性衰减后更换 |
| 超细纤维布 | 水洗晾干，避免与深色衣物混洗 |

### 4.4 售卖口径

- 零售单品；C1/C2/C3/C5/C4/B1 各包装内已含基础清洁配件，K1 为补充装与批量采购装。
- 建议话术：贴膜服务 + K1 带回家，日常自己也能清洁维护。

## 5. G1 指环支架规格书

### 5.1 基本参数

| 参数项 | 规格 |
| --- | --- |
| 型号 / 品名 | G1 指环支架 |
| 结构 | 360° 旋转指环，多角度支架使用 |
| 磁吸组件 | 内置 N52 磁吸环 |
| 主体材质 | 锌合金指环 + ABS 底座（以实物为准） |
| 适配 | 可直接吸附于 T20 MagSafe 透明壳、MagSafe 磁吸面；非磁吸机型需选配金属贴片（另购） |
| 单个净重 | 约 25g（以实物为准） |
| 包装 | 独立盒装，含说明书×1 |

### 5.2 使用方式

| 场景 | 用法 |
| --- | --- |
| 指环防摔 | 食指穿环握持，降低滑落风险 |
| 横竖支架 | 指环翻折 360° 调节支撑角度，横竖屏皆可 |
| 磁吸车载 | 吸附于磁吸车载支架；非磁吸车架机型用金属贴片过渡 |
| 与 T20 组合 | G1 吸附在 T20 磁吸壳背面即可随时取放 |

### 5.3 注意事项

- G1 磁吸功能对无 MagSafe 模块的机型不直接生效，必须配合金属贴片使用。
- 磁吸面避免与银行卡、门禁卡等磁条卡片长时间直接接触。
- 指环转轴为精密结构，禁止暴力扭转与悬挂重物。

### 7.2 常见问题 FAQ

| 问题 | 标准答复 |
| --- | --- |
| P1 能贴 C5 陶瓷膜吗？ | 不能。C5 为全胶一次对位工艺，建议直接对位贴装；P1 仅适配 C1/C2/C3。 |
| P1 是所有机型通用吗？ | 不是。P1 按机型开模，购买前需核对机型，跨机型不可通用。 |
| K1 里的湿巾能擦镜头吗？ | 可以。酒精湿巾可用于镜头组清洁，贴膜与镜头膜安装均适用。 |
| G1 装在安卓机上能磁吸吗？ | 不能直接磁吸。安卓机无 MagSafe 模块，需配合金属贴片（另购）使用。 |
| G1 能承重悬挂吗？ | G1 为指环支架，仅用于穿环握持与支架场景，禁止悬挂重物。 |
| 三片装赠的 P1 机型不匹配能换吗？ | 可以，凭订单在门店兑换对应机型 P1。 |
