## 1. 文档说明

- 本规格书覆盖膜法工坊（MofaLab）两款裁切型膜材：**C4 水凝膜（TPU 屏幕膜）** 与 **B1 磨砂背膜（PET 背面贴膜）**。
- 两者均为整片出厂、按机型裁切使用，是曲面屏与未开模机型的兜底方案。
- 机型适配判定见《机型适配总表_钢化膜与水凝膜》（MF-SX-2026-001）与《机型适配总表_手机壳与背膜》（MF-SX-2026-002）；裁切设备见《膜切机规格书_MC300_MC500》（MF-SP-2026-006）。

### 3.2 材质与工艺

- TPU 弹性基材柔韧可延展，能完整包覆大曲率曲面屏，是钢化膜（C1/C2/C3/C5）无法覆盖的曲面屏唯一方案。
- 表面自修复涂层受轻微划伤后，常温下 24~48 小时内自动回填修复；深层割伤无法修复。
- 硅胶自吸附层无残胶，可揭起调整；膜体可轻微拉伸，便于曲面边缘收边。

### 3.5 应用场景与卖点

- 核心场景：华为 Mate 60 Pro/60 Pro+/70 Pro 等大曲率曲面屏机型的屏幕防护。
- 核心话术：TPU 柔性全包曲面、细微划痕自动修复、无胶无残胶。
- 客服话术要点：
  - 直板机可以贴 C4，但钢化膜（C1/C2）防刮耐冲击更优，直板机优先推荐钢化膜。
  - C4 无法像钢化膜那样「一贴即平」，贴后残留细小气泡属正常，一般 24~48 小时内自动消散。

### 3.6 贴装与裁切注意事项

1. 裁切前在「膜切云」APP 中核对机型与刀模编号，避免错裁。
2. 手工裁切仅限无膜切机的应急场景，需使用随附刮卡与锋利刀片，沿机型模板线一次成型。
3. 贴装前确保屏幕彻底清洁（酒精湿巾 → 纤维布 → 除尘贴逐级除尘）。
4. 曲面屏贴装后用刮卡自中心向两侧收边，边缘翘边可用热风枪低温（≤60℃）轻微加热定型。
5. 贴后 12 小时内避免高频触控边缘区域，以保证吸附层稳定。

## 4. B1 磨砂背膜规格书

### 4.1 基本参数

| 参数项 | 规格 |
| --- | --- |
| 型号 / 品名 | B1 磨砂背膜 |
| 材质 | 磨砂 PET |
| 厚度 | 0.1mm |
| 表面处理 | 哑光磨砂（防指纹） |
| 透光率 | 不适用（背面贴膜无光学显示要求） |
| 出厂形态 | 整片未裁切（按机型裁切后使用） |
| 裁切方式 | 膜切机（MC-300/MC-500）裁切或手工裁切 |
| 单片净重 | 约 3g（以实物为准） |
| 适配机型 | iPhone 全系及主流安卓直板机（逐机型矩阵见 MF-SX-2026-002）；折叠屏暂不支持 |

### 4.2 材质与工艺

- 0.1mm 磨砂 PET，哑光表面消除玻璃背板指纹与滑腻感，提升裸机握持摩擦力。
- 低粘硅胶层，贴附平整、撕除无残胶，不损伤原背板镀层。
- 可按机型裁切精确避让摄像头 Deco、Logo 与无线充电区域，不影响 MagSafe/无线充电（金属材质配件才会屏蔽磁场，PET 膜不影响）。

### 4.5 应用场景与卖点

- 适用人群：习惯裸机但担心玻璃背板刮花的用户；二手保值需求用户。
- 核心话术：磨砂防指纹、0.1mm 无感、撕除无残胶。
- 建议搭配：与 C1/C2 屏幕膜组成「前后全套」防护，门店可做组合价。

### 4.6 贴装注意事项

1. 背膜必须按机型裁切后使用，禁止将整片直接贴附。
2. 摄像头 Deco 区域裁切需预留 0.5mm 余量，避免翘边（以膜切云刀模数据为准）。
3. 曲率较大的背板（如曲面后盖机型）贴装时需缓慢收边，气泡用刮卡推出。
4. 贴后 12 小时内避免佩戴过紧的手机壳，防止边口起翘。

| C4 水凝膜 | 支持 | 支持 | 应急支持 |

- MC-300 内置 12000+ 机型刀模库，切幅 90mm，覆盖 C4/B1 常规机型裁切。

- 刀模库通过「膜切云」APP 每月更新新增机型清单，新机型发布后 14 个自然日内上线；未上线机型用 C4/B1 整片 + 手工裁切过渡。
