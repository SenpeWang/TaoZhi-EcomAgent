## 1. 退换货流程（文字版流程图）

### 1.1 无理由退货流程

```
客户申请（订单页/热线 400-680-9527）
    ↓
客服核验时效与商品状态
（7 天内？离型膜未撕/包装完整/附件齐全？）
    ↓ 通过                 ↓ 不通过
审核通过，下发退货地址      说明除外条款（撕膜/划损不支持），
（系统短信自动推送）        引导换新或维权路径终止
    ↓
客户寄回（运费客户承担，填写运单号）
    ↓
仓检（1 个工作日：外观/附件/防拆标签）
    ↓ 通过                ↓ 不通过
原路退款（1~3 个工作日）    拍照留证退回商品并说明原因，
                           客户可申请人工复核 1 次
```

### 1.2 质量问题换新流程

```
客户提交照片/视频（15 天内，含凭证）
    ↓
客服初判（1 个工作日）→ 非人为质量问题？
    ↓ 是
寄回旧件（运费公司承担，到付）
    ↓
质检复判（2 个工作日，对照 MF-QC-2026-001/002 指标）
    ↓ 确认
48 小时内发出新品（重新起算 15 天换新期）
    ↓ 判定为人为损坏
转人为责任沟通（可付费维修/不处理），安抚升级见第 4 节
```

### 1.3 设备维修流程

```
报修（热线/经销商系统，提供机身序列号+故障视频）
    ↓
4 小时内远程诊断
    ↓
├─ 可远程解决 → 指导操作 → 关单回访
├─ 质保期内硬件故障 → 寄修/上门（UV 设备 3 个工作日内到店）
└─ 质保外/人为损坏 → 出具报价 → 客户确认后付费维修
    ↓
维修完成 → 客户验收 → 工单关闭 → 7 日内回访
```

## 2. 工单分级与响应 SLA

| 级别 | 定义（示例） | 响应时限 | 处理时限 | 责任人 |
| --- | --- | --- | --- | --- |
| P0 重大 | 安全事故（设备漏电、碎膜割伤）；批次性缺陷集中爆发（≥5 起/批）；舆情发酵（社交媒体扩散） | 15 分钟内 | 24 小时内给出处置结论，批次召回同步启动 | 售后主管 + 质量管理部 |
| P1 严重 | 设备无法使用且远程未解决；同订单第三次投诉；经销商整箱质量异常 | 30 分钟内 | 48 小时内出方案 | 售后主管 |
| P2 一般 | 质量问题换新、切歪/连不上蓝牙等技术求助、物流破损 | 2 小时内 | 3 个工作日内闭环 | 一线客服 |
| P3 轻微 | 发票信息、咨询类、单件物流延迟 | 4 小时内 | 5 个工作日内闭环 | 一线客服 |

规则：

1. SLA 以工单系统时间戳为准，超时未响应自动升级至上一责任人。
2. P0 工单须同步邮件通报渠道管理部与质量管理部；涉安全事件 2 小时内电话回拨客户。
3. 每日 9:30 晨会复盘前一日超时工单，连续两周达成率 <95% 的班组启动专项辅导。

## 3. 客服沟通四步法

所有售后触点统一执行「**先安抚 → 再核实 → 给方案 → 给补偿**」：

| 步骤 | 要点 | 话术示例 |
| --- | --- | --- |
| ① 先安抚 | 先处理情绪再处理事情；不打断、不辩解、不推责 | 「非常抱歉给您带来不便，您的心情我理解，我来帮您处理。」 |
| ② 再核实 | 固定证据：订单号、照片/视频、机型、批次号；按 FAQ 知识库核对场景 | 「方便拍一张未撕膜的全景和起泡位置的特写吗？」 |
| ③ 给方案 | 按政策给出 1 个主方案 + 1 个备选方案，明确时效 | 「第一种 15 天内免费换新，运费我们承担；第二种全额退款。」 |
| ④ 给补偿 | 超时、体验受损时按第 5 节赔付标准主动补偿，不等客户索要 | 「这次发货延迟了 2 天，我们按标准补偿您 10% 的订单金额。」 |

禁止行为：与客户争辩责任归属、承诺政策外补偿、未经授权引导客户拒收物流件。

## 4. 升级路径

```
一线客服（P2/P3）
    ↓ 首次方案客户不接受 / 客户明确要求
售后主管（P1，2 小时内接管）
    ↓ 人为/非人为判定争议 / 补偿超权限 / 48h 未闭环
售后经理（P0，24 小时内接管）
    ↓ 涉批次质量 → 联合质量管理部（对照出厂检验报告）
    ↓ 涉经销商责任 → 联合渠道管理部仲裁
    ↓ 仍无法达成一致 → 终局仲裁
客服总监裁定（3 个工作日内），结果为最终处理意见
```

1. 升级须在工单系统记录「升级原因 + 已提供方案 + 客户诉求」，禁止无记录甩单。
2. 判定争议（如「撕膜」归属）以客户提供的时间戳证据 + 物流签收时间为准，举证不足时**偏向客户**处理。
3. 经销商与终端客户的售后责任划分：质量问题属公司 → 公司承担；属经销商仓储/二次物流损坏 → 经销商承担，有争议按仲裁流程裁定。

## 5. 赔付标准表

| 情形 | 赔付标准 | 上限/说明 |
| --- | --- | --- |
| 发货超时（无理由期订单） | 每 24 小时赔实付金额 5% | 上限 30%；不满 24h 按 24h 计 |
| 承诺换新超时 | 每 24 小时赔实付金额 10% | 上限 100%，超 7 天客户可选退款 |
| 质检复判为质量问题且客户已垫付寄回运费 | 运费全额报销 | 凭运单号，随退款到账 |
| 物流破损（公司包装责任） | 免费补发 + 赠 K1 清洁套装 1 份 | 设备类破损直接换新机 |
| P0 安全事件 | 医疗费用实报实销 + 慰问金 200~1000 元 | 需售后经理审批，24h 内先行垫付医疗费 |
| 客服服务态度问题（质检坐席实锤） | 道歉 + 无门槛优惠券 20 元 | 同一工单不重复计发 |
| 误判人为责任（复核推翻） | 恢复换新权益 + 补偿实付金额 10% | 售后经理签发 |

补偿形式：货款抵扣券（有效期 6 个月）或原路现金退款，客户二选一；单工单补偿总额超过实付金额 100% 须经客服总监审批。

## 6. 工单记录规范

### 6.1 必填字段

| 字段 | 说明 |
| --- | --- |
| 工单级别 | P0~P3，误判级别由主管考核 |
| 客户/渠道 | 终端客户（订单号）或经销商（B2B 编号） |
| 涉及 SKU 与批次号 | 按《SKU货品档案》（MF-PH-2026-001）规范填写 |
| 问题分类 | 贴膜类/机型适配/设备类/订单政策类（对齐 FAQ 知识库分组） |
| 判定结论 | 质量问题（非人为）/人为/使用正常现象（对齐质检标准口径） |
| 处理方案与补偿 | 主方案+备选方案+补偿金额（对照第 5 节标准） |
| 时间戳 | 受理/响应/闭环各节点系统自动记录，作为 SLA 依据 |

### 6.2 数据指标看板

| 指标 | 目标 |
| --- | --- |
| SLA 达成率 | ≥ 98% |
| 一次解决率（FCR） | ≥ 85% |
| 工单闭环平均时长 | P2 ≤ 2 个工作日、P3 ≤ 3 个工作日 |
| 7 日复诉率 | ≤ 3% |
| 客服满意度（回访） | ≥ 4.6/5.0 |

## 7. 工单关闭与回访

1. 工单闭环标准：客户确认问题解决，或方案执行完毕后 48 小时无异议。
2. P0/P1 工单关闭后 7 日内电话回访；回访不满意的自动重新开启并升级一级。
3. 月度输出《售后质量分析报告》：Top5 问题场景、批次质量预警、FAQ 知识库增补建议，抄送质量管理部与商品管理中心。
