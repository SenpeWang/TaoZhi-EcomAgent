## 1. 培训目标

完成本手册学习并通过《客服上岗考核题库》（MF-PX-2026-002）后，新员工应能：①说清公司全系产品线；②准确判断机型适配；③掌握核心售后政策口径；④知道每类问题查哪份文档。

## 2. 公司与产品线总览

膜法工坊（MofaLab）是手机配件品牌，围绕「手机贴膜 + 定制出膜 + 个姓定制设备」构建产品体系，三大产品线：

| 产品线 | 产品 | 一句话定位 |
| --- | --- | --- |
| 膜类 | C1/C2/C3/C4/C5/L1/B1 | 从高清到防窥、曲面到折叠屏的全场景贴膜方案 |
| 壳类与配件 | S10/T20/A30、P1/K1/G1 | 保护壳 + 贴膜工具 + 周边配件 |
| 设备 | MC-300/MC-500 膜切机、UV-600/UV-900 UV 打印机 | 门店切膜与个姓定制打印的硬件底座 |

## 3. 核心概念科普（新人必懂 6 讲）

### 3.1 钢化膜工艺

钢化玻璃经钢化处理提升抗冲击与表面硬度，配 AF 防指纹镀层。硬度标称 9H（如 C1），数字越高抗刮性越强，但「9H」是铅笔硬度体系的营销口径，不等于「防摔」，摔落保护主要靠碎膜吸能——钢化膜本身就是「牺牲膜」，碎了换膜即可，别慌。

### 3.2 疏油层（AF 镀层）

降低表面张力，让汗渍油渍不挂壁、水滴成珠滚落。手感「滑不滑」取决于疏油层质量。判别方法：滴水成珠、倾斜滚落无挂壁 = 疏油层正常；疏油层磨损属正常损耗，不在售后范围。

### 3.3 MagSafe 磁吸标准

苹果磁吸配件标准，T20 透明壳内置 N52 强磁环，拉脱力 ≥8N，适配 iPhone 12~17。客户问「吸得牢不牢」就答 N52 磁环 + ≥8N 拉脱力。注意：MagSafe 是 iPhone 12 起的机型特性，iPhone 11 及以前机型无法磁吸。

### 3.4 水凝膜与钢化膜的区别

| 维度 | 水凝膜（C4） | 钢化膜（C1/C2/C3） |
| --- | --- | --- |
| 材质 | TPU 软膜，0.12mm | 钢化玻璃（C1 0.33mm / C3 0.38mm） |
| 适配 | 曲面屏（可包边） | 直板屏 |
| 特性 | 细小划痕可自动修复 | 抗冲击、碎膜吸能 |
| 手感 | 软、无玻璃感 | 硬、顺滑 |
| 防窥 | 无 | C3 支持 28° 防窥 |

一句话：**曲面屏找 C4，直板屏看需求选 C1/C2/C3，折叠屏找 C5**。

### 3.5 膜切机商业模式

门店购入 MC-300/MC-500 后，通过「膜切云」APP 调用云刀模（12000+/20000+，每月更新并推送当月新增机型清单，新机型刀模自机型发布起 14 个自然日内上线），按需现切现卖膜片，实现：不压库存、新机型刀模月更即卖、一张原料出一片（边角损耗低）。设备是「印钞机」，刀模库是「弹药库」——这就是门店续费云刀模的动力。

### 3.6 UV 打印

UV-600/UV-900 用 UV 墨水经紫外光即时固化，可打印手机壳、圆瓶（UV-900 滚轴圆面）等介质。关键概念：白墨（W-1L）用于深色介质打白底、必须每日循环防沉淀；介质不同需选择不同 ICC 色彩曲线；喷头 XP600 精度 1440dpi。

## 5. 机型适配判定三步法

客服接到「我的手机能用哪款」时的标准动作：

1. **第一步：确认机型**。要求客户提供精确型号（设置-关于本机），禁止凭客户口述「Pro Max 大概吧」下单。
2. **第二步：判定屏幕形态**。直板屏 / 曲面屏 / 折叠屏：直板→C1/C2/C3（C3 限 iPhone 14~17 直板）；曲面→C4 水凝；折叠→C5 陶瓷。
3. **第三步：按需求收敛**。高清→C1；防指纹磨砂→C2；防窥→C3（且机型匹配）；镜头保护→加 L1；磁吸需求→T20（iPhone 12~17）。

速记口诀：**直板 C1C2C3，曲面 C4，折叠 C5，镜头 L1 背面 B1**。

## 6. 常见错误问答示例（新人易错对照）

| 错误说法 ❌ | 正确口径 ✅ |
| --- | --- |
| 「C3 防窥膜安卓机也能贴」 | C3 仅适配 iPhone 14~17 直板机型，安卓直板/曲面均不适用 |
| 「C4 水凝膜能贴曲面屏也能贴直板」 | C4 为曲面屏设计，直板机首选 C1/C2/C3 |
| 「MC-300 什么膜都能切」 | MC-300 仅支持 C1/C2/C4/B1，切幅 90mm；C3/C5 需 MC-500 |
| 「设备终身保修」 | 设备整机 1 年质保，喷头 3 个月，耗材（N1/M3/墨水）不保修 |
| 「膜贴坏了包赔」 | 膜 7 天无理由（已撕膜不支持）；非人为脱胶 15 天换新 |
| 「T20 全机型通用」 | T20 适配 iPhone 12~17（MagSafe 特性 iPhone 12 起） |
| 「壳发黄是质量问题」 | S10 液态硅胶氧化发黄属材料正常现象 |
| 「蓝牙连不上是设备坏了」 | 优先排查 2.4GHz 频段（设备仅支持 2.4GHz） |
| 「UV 白墨一周循环一次就行」 | 白墨 W-1L 必须每日循环，防沉淀堵头 |
| 「刀头断了免费换」 | N1 属耗材，约 3000 次寿命，不保修，可参与以旧换新咨询 |
