## 知识库使用

选择资料并上传到对应租户的「知识文档」，沿用现有解析与发布审批。入库后按 PDF 文件页序保留引用页码。使用法规时核对适用地区和日期，使用商品资料时核对型号及版本。开放硬件和研究论文适合解释技术原理，店铺售价、实时库存与售后承诺以对应业务记录或已批准条款为依据。
