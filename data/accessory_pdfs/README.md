# 手机配件 PDF 资料包

本目录提供可下载的原版 PDF，覆盖充电器、USB-C 线材、无线充电、移动电源、手机支架、集线器、保护膜、手机壳和耳机。按样品型号查验充电宝、无线充和蓝牙耳机时，可以先读市售抽检或测量报告。具体产品规格和安装条件可从厂商官网 PDF 查阅。

## 知识库使用

自行嵌入时可读取清单的 `files`，按 PDF 文件页序切片并保留型号、版本和来源。需要通过工作台入库时，上传到对应租户的「知识文档」，沿用现有解析与发布审批。引用抽检价格、合规结果与测量数据时带上取样时点、地区及测试条件。部分监管报告的附页使用图片，提取不到文字的表格可直接查看 PDF。店铺售价、实时库存及售后承诺以业务记录或已批准的条款为依据。
